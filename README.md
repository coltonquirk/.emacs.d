# .emacs.d

This is my personal emacs configuration that I am 
creating following System Crafters "EMACS from Scratch" series, 
Mastering EMACS, and my own research.

I would like this configuration to allow for:
- Development of scientific computing programs in Julia, Python, and Fortran
- Personal Knowledge Management/note taking of research papers and ideas
- Writing of technical documents, either reports or papers
- Integration with quarto and typst as well for working with personal projects
